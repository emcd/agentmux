## Context

The frozen wire (`add-agent-adapter-contract`, 6 specs, 35 requirements, 54 scenarios, merged `4e05525d`) defines NDJSON JSON-RPC 2.0 over stdio with methods `adapter.handshakeHello`, `adapter.requestChoice`, `relay.look`, `adapter.submit`, `adapter.persistState`, `adapter.lifecycleEvent`, `relay.supervisionSignal`. No adapter code exists in-tree (`src/` has no adapter module); Backend owns the supervisor/hosting side (step 3 `DeliveryContext`, supervisor slice); QA Partner co-owns the conformance suite (task 3.2). The off-tree corpus/checker scratch (33 frames) informed spec review but is gitignored. Semantic cross-check: `ideas/mcp/4` (submit = authorized-send transport, requestChoice = decide, look = look).

## Goals / Non-Goals

**Goals:**

- First executable validation of the frozen contract, adapter side only.
- Bit-for-bit deterministic wire behavior for a given frame script (conformance-seedable).
- Crate/binary layout fixed in this change so implementation has a skeleton to fill.

**Non-Goals:**

- No supervisor, hosting, `DeliveryContext`, or `src/relay` changes.
- No ACP-profile agent child (scripted generic profile only; ACP follow-on later).
- No conformance-suite execution (task 3.2, joint with QA) — this change plans its inputs and cases only.
- No SDK types on the wire; protocol behavior only.

## Decisions

- **Crate layout: `src/adapter/` library + `agentmux-adapter` binary.** Library modules: `frame` (NDJSON read/write, dual inbound bounds, 64KiB bootstrap ceiling, `-32000` error shape with correlation discipline), `reply` (originated-reply shape validation before admission, echo exemptions, keep-open on malformed), `binding` (bootstrap establishment from hello result, then captured-binding plus direction plus wire-id pending-table admission, never inferred), `handshake` (major equality plus minor-window overlap, matched-pairs limit resolution, mandatory `latency_declarations`, per-iteration deadline plus overdue-match rejection), `submit` (single-flight gate, scripted turn execution, ack trichotomy incl. `RefusedBusy`), `choice` (raise + block resolver, dual-cancel on disconnect, record-before-respond), `look` (tail-N snapshot windows with entry counts, adapter-side prime-wait, preserved truncation flags), `persist` (write submission, tag-echo, duplicate-id tracking client-side), `lifecycle` (ready/degraded/failed emission, never dictating supervision outcome; `ManualClock` test double with wall-slice recv so a frozen virtual clock cannot starve the drain watchdog), `script` (fixture-script interpreter driving turns), `writer` (threaded transport sink: separate bounded per-lane channels, take-first writer with mandatory same-iteration recheck and held data, depth-1 coalesced notify, run-loop-owned deferred-control counter gating new data takes), `outbound` (lane-checked admission with bounded deferred queues: append-behind rule per lane, control-first flush each turn, lockstep quiesce seam), `teardown` (progress-aware stuck-writer watchdog with completed-write refresh, connected bounded shutdown drain with per-turn flush, terminalization that preserves failure state and writes nothing on a dead channel). Binary `src/bin/agentmux_adapter.rs` stays thin: argv parse, stdio loop, exit codes. Alternative (single-file binary) rejected: the conformance suite needs to drive the library without spawning for unit-level round-trip cases. New-obligation homes (writer, outbound, teardown modules grown from the original nine): outbox bounds, queue caps, and the control lane live in `writer`/`outbound` (per-lane channels plus per-lane deferred queues, control exempt from data caps within its own negotiated bound); originated-call in-flight caps and the pending-call table live in `choice` (persist writes tracked in `persist`); ping/pong liveness lives in `lifecycle` alongside the local diagnostic/inspection sink (shed gate-drops, cleanup records); per-type cancel/cleanup terminalization lives in each method module (`submit`, `choice`, `look`, `persist`), coordinated through `teardown` terminalization.
- **Scripted generic profile first.** Turns follow a fixture script (TOML): on submit → emit scripted lifecycle events, optionally raise scripted `requestChoice`, ack per script. Alternative (ACP agent child now) rejected: a child process introduces nondeterminism the first validation must not have; the contract's generic profile exists exactly for this.
- **Deterministic virtual clock, no randomness.** All waits derive from supervisor-passed timeouts expiring only on fixture-driven virtual-clock advances carried as first-class trace events, with deterministic dispatch ordering; the live executable feeds the same injected clock from a monotonic source, and replay guarantees cover identical traces only. Randomness is absent from wire-decision paths (single rule, stated here; the spec's ban is this rule). Time source is a trait with a manual test implementation; no `SystemTime`/`rand` in wire-decision paths (grep-auditable). Scripted submission evidence models a fake agent effect boundary, not proof of real-agent acceptance. Alternative (real clock with tolerances) rejected: conformance transcripts must be byte-comparable.
- **In-tree fixtures as the conformance input source.** `tests/fixtures/adapter/`: scripts, request/response transcript pairs, adversarial frames (skew, oversize, unknown correlation, duplicate acks). The off-tree 33-frame corpus informs coverage; ACP points at it during review. Alternative (depending on scratch) rejected: gitignored inputs cannot gate CI.
- **Frozen contract governs all adapter-side obligations.** This change restates the adapter-exercised subset (framing, handshake, submit, choice, look, persist, lifecycle, plus the requirements below) and adds scripting, determinism, and conformance planning. Where this spec is silent, the contract text governs — the restated subset never narrows the normative contract. Supervisor-side authority (watchdog triggers, cessation observation, store commit/pointer advance, generation publication) is explicitly out of scope and is never implemented here.

- **No relay imports.** The adapter module's wire and product-boundary types use only std + serde/serde_json; fixture/script parsing may additionally use the existing `toml` dependency. The restriction that matters is product-boundary imports (no relay, MCP, transport, acp, tmux, or pty types) — opaque handles only, per the contract's no-back-edge requirement. Enforcement is review plus extension of `scripts/lint-delivery-protocol-boundary.py` to `src/adapter/` plus a dependency-direction test task. Violation is a review-blocking defect.
- **Dead transport: a non-draining peer loses the session rather than dropping a reply.** Data and control ride separate bounded per-lane channels behind the writer thread plus per-lane bounded deferred queues: a full lane defers the frame (counted against the negotiated caps) and reports success, so the run loop never parks inside a send — it flushes deferred control first, then deferred data, at every turn — and a disconnected queue terminalizes the session locally with no wire reply required (the frozen dead-channel rule). At every intact frame boundary the threaded writer serves queued control ahead of further queued data (take-first with a mandatory same-iteration recheck and held-data rule), and a run-loop-owned deferred-control counter makes admitted-but-unflushed control visible to the writer so held data waits for the deferred tail; wakeups are bounded and coalesced (depth-1 channel, recheck on wake, so none is lost). Control traffic is accounted on its own negotiated control bound (allowance 32 exceeds the sixteen-deep channel as an ordinary supported state), exempt from data caps, and control admission failure escalates the same way. A full drain wait with zero completed writes fails the session via the loop-top watchdog, which is progress-aware (completed writes refresh the stall clock; wall-slice recv keeps a frozen virtual clock from starving it) — never a single blocked send. A peer that stalls with zero completed writes for the whole drain wait therefore loses the session — while a merely slow but progressing writer keeps refreshing the watchdog with every completion and never trips it — instead of shedding one reply. Deliberate and contract-sanctioned, not a shortcut: the alternative (unbounded queueing, or answering over a dead channel) is what the contract forbids. Alternative (non-blocking stdout with poll(2) multiplexing stdin) rejected: a writer thread in std keeps the library portable. Deterministic replay is an explicit draining entry (`run_replay_stdio`): per-enqueue quiesce plus per-turn flush quiesce make replayed wire order exactly the enqueue order under every schedule; live-scheduling variance stays out of scope per the frozen text.

## Risks / Trade-offs

- [Script expressiveness vs determinism] → Mitigation: script language covers only the contract's observable behaviors (acks, choices, snapshots, events); anything richer waits for the ACP follow-on.
- [Fixture drift from frozen contract] → Mitigation: every fixture cites its requirement; contract revision (not this change) owns updates.
- [Supervisor absence limits validation depth] → Mitigation: a harness-side test double plays supervisor per the contract (pending-table admission, watchdog triggers) for round-trip cases; real supervisor interop is step-4 work.
- [ACP-profile gap] → Mitigation: documented follow-on; generic-profile validation does not claim ACP coverage.

## Migration Plan

Additive only: new module, new binary, new fixtures. No existing behavior changes; no rollback beyond revert. The binary is not wired into any supervisor or release path by this change.
